# Contributing to node-api

This is the rhdh-parasol node-api playground, a simple REST API for task
management. Contributions are welcome!

## Proposing a change

1. Fork the repository or create a branch off `main`.
2. Make your changes on the new branch.
3. Open a pull request back to `main`.

## Pull request expectations

- Include a clear description of **what** changed and **why**.
- Keep changes focused — one logical change per PR.
- If a related issue exists, link it from the PR (e.g.,
  `Closes #123` or `Related to #123`).

## Running the project locally

```bash
npm start        # start the server
npm test         # run the test suite
```

## Questions?

Open an issue and we will be happy to help.
